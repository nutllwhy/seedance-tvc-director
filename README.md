# Seedance TVC Director

一个面向 Seedance 2.5 商业广告创作的导演型 Skill。它把产品 brief、参考图和传播目标转换为 15 秒、30 秒或自定义时长的 TVC 策略、导演执行单、分镜预览与可复制视频提示词，也能根据生成成片的时间码证据给出局部重试方案。

当前版本：`0.17.0`

## 它解决什么问题

视频模型会生成漂亮画面，但商业广告还需要回答更多问题：

- 前三秒有没有真正抓住注意力；
- 30 秒是否增加了新场景和新信息，而不是把 15 秒动作拉长；
- 产品是否参与故事因果，而不是最后突然贴片；
- 旁白是否只说一次，并与镜头节奏正确配合；
- 包装、手部、人物身份和物理动作是否连续；
- 生成失败后，能否只修证据指向的层，而不推翻已经成功的部分。

`seedance-tvc-director` 将这些判断编译为可执行规则，并持续用真实生成视频做回归。

## 主要能力

- `15 秒 / 30 秒 / 自定义秒数`三个时长路由；
- `有旁白 / 无旁白 / 同时生成两套完整版本`三个独立声音选项；
- `直出 / 九宫格预览`两种生成方式；
- 0–3 秒广告钩子与首尾状态检查；
- 30 秒多场景推进、镜头密度与反重复控制；
- 12–16 镜高密度接力蒙太奇、场景锚与全局运动方向；
- 跨世界视觉母题、环境声床和声音先行转场；
- 唯一旁白真源、硬停止时间与重复发声防护；
- 当代美妆选角、多人身份与座位连续性；
- 开袋、滴液、涂抹、倒出等产品动作的真实受力链；
- 食品口感与具体风味的可见证据链；
- 无数字、无时间码、无标签的九宫格分镜；
- 基于硬切、逐秒抽帧和带时间码转写的成片复盘；
- 动作完成态、转场空帧、hero reveal 与 packshot 预算检查。

## 安装

### Codex

克隆仓库，然后把 Skill 文件夹放进 Codex Skills 目录：

```bash
git clone https://github.com/nutllwhy/seedance-tvc-director.git
cp -R seedance-tvc-director/seedance-tvc-director ~/.codex/skills/
```

也可以保留为项目本地依赖，在任务中明确让 Agent 读取仓库里的 `seedance-tvc-director/SKILL.md`。

### 其他 Agent

将 `seedance-tvc-director` 文件夹放进当前 Agent 支持的 Skills 目录。九宫格生图不会硬编码具体供应商：Skill 会优先使用当前 Agent 已经提供的原生生图能力。

## 最简单的使用方式

```text
使用 $seedance-tvc-director，为这个产品做一支30秒TVC。
声音选择有旁白，生成方式选择直出。
这是产品图和卖点，请先给我完整提示词。
```

如果没有说明配置，Skill 会一次性确认三个互不绑定的选项：

1. 时长：15 秒、30 秒或自定义秒数；
2. 声音：有旁白、无旁白或同时生成两套完整版本；
3. 生成方式：直出或九宫格。

直出模式给 Seedance 更大的自然运镜空间；九宫格模式会先生成无标记分镜预览，等待确认后再编译视频提示词。

## 用成片继续迭代

生成后可以把视频重新交给 Skill：

```text
使用 $seedance-tvc-director 复盘这支成片。
请保留已经成功的产品、人物和旁白，只根据时间码修最主要的问题。
```

推荐同时提供：

- 生成平台与版本；
- 时长、声音和直出/九宫格配置；
- 实际使用的提示词与参考素材职责；
- 原始生成视频或可访问链接；
- 你认为有问题的准确时间码；
- 希望保留的成功部分。

Skill 会先区分成功层与失败层，再输出保留项、唯一主修层和重试指令。

## 设计结构

```text
brief 与事实边界
  → 三个独立生成配置
  → 单一核心主张
  → 前三秒广告钩子
  → 15/30/自定义时长结构
  → 人物、产品、声音和场景锁
  → 场景锚、镜头交接与声音桥
  → Seedance 2.5 提示词编译
  → 交付前 QC
  → 成片抽帧、切点与转写复盘
  → 局部重试与回归用例
```

详细规则按需放在 `seedance-tvc-director/references/`，核心路由保留在 `SKILL.md`，真实失败案例被压缩为 `evals/evals.json` 中的回归断言。

## 如何参与迭代

欢迎使用这个 Skill 生成案例，并通过 GitHub Issue 提交复盘材料。建议标题使用：

```text
[案例反馈] 产品类别 / 15秒或30秒 / 直出或九宫格
```

Issue 正文建议包含：

```text
生成平台与版本：
时长：
声音模式：
生成方式：
产品类别：
提示词或相关片段：
视频链接：
问题时间码：
希望保留的部分：
你希望改进的结果：
```

请不要提交保密 brief、未获授权的客户素材、个人隐私或无法公开的视频。品牌名称与商标归各自权利人所有。

## 边界

- 这是导演与提示词编译 Skill，不保证任何平台的生成效果、参数上限或商业可投放性；
- 精确 Logo、包装小字、价格、CTA、免责声明和播出级旁白应由后期使用获批资产完成；
- 未经验证的功效、数据、认证和绝对化表达必须保留为待补项；
- Seedance 2.5 的实际能力可能因入口和时间变化，使用前请以当前平台为准。
